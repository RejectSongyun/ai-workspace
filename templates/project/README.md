# 通用项目模板

本目录仅包含协作记录与产品入口，不规定源码布局或技术栈。使用 tools/Initialize-AipProject.ps1 初始化；工具仅复制 .ai 与 AGENTS.md。协议快照来自 workspace protocol/，technology 元数据可以完全省略。

固定快照版本为 0.2.2。协议演进体系留在 workspace evolution/；项目通过 .ai/protocol/evolution.yaml 了解证据边界，脱离 workspace 时仍保留禁止自行晋升的门禁。

可选 Insight Pass 模板在 `.ai/protocol/templates/`，Schema 在 `.ai/schema/`；仅在预算获授时复制到对应 Task，不为简单任务强制填表。
